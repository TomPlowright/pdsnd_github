### Project Title
US Bikeshare Data Analysis 

### Description
This project analyses bikeshare data from three major US cities: Chicago, New York City and Washington.

The purpose of the project is to explore how people use bikeshare services and identify patterns in travel behaviour.

The project investigates:

The most popular times of travel.
The most frequently used stations.
The duration of bike trips.
User demographics.
Differences in bikeshare usage between cities.

### Files used
The project includes the following files:

bikeshare.py – The Python script used to analyse the bikeshare data.
new_york_city.csv – The New York City bikeshare dataset.
.gitignore – A file used to prevent the CSV data file from being tracked by Git.

The project uses Python Libraries including Pandas and NumPy to process and analyse the data.

The CSV dataset is excluded from version control to avoid uploading data files unnecessarily

The goal of this project is to practise Python programming and data analysis by exploring real-world bikeshare data.

### Analysis Approach

The bikeshare project uses Python to explore and analyse cycling data.

The analysis focuses on identifying trends in bike usage, including:
- Popular travel times.
- Trip duration patterns.
- Frequently used starting and ending stations.
- Differences in usage between customer types.

These insights help provide a better understanding of how bikeshare services are used.
